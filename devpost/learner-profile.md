# Learner Profile

## Initial Idea
ProofPath AI: a career-readiness app for students and recent graduates applying for internships, including entry-level data analyst roles. A user enters an internship description and their skills/projects; the app identifies role skills, compares evidence without overstating experience, highlights gaps, and creates a specific seven-day portfolio project plan. The first prototype should support one workflow: enter inputs, assess gaps, create an action plan, and view or download a report. The learner prioritizes a working demo and a scope that fits the hackathon, and asked not to use old code.

## Demonstrated Technical and Agent Experience
Beginner developer. Has made small projects using AI and has recently been using OpenAI Codex as an AI coding agent.
Evidence: “I am a beginner developer” and “I have made some small projects using AI in the past.”

## Planning-Workflow Experience
New to formal project planning with documents. Has not used scope, product requirements, and technical specification documents as a project planning process.
Evidence: “I have no experience of the proper way of planning a project with the help of documents such as scope document, product requirement document, and technical specification document.”

## Desired Learning Outcome
Learn how to plan a project before coding and understand decisions made during the project.
Evidence: “I would like to learn about making plans for a project before coding and understanding decisions taken during the project.”

## Interests, Inspirations, and Goals
Interested in helping students and recent graduates understand concrete internship skill expectations and show credible evidence of their skills.

## Vocabulary and Concepts Likely to Need Explanation
Explain unfamiliar tools and planning concepts in accessible terms; the learner explicitly requested explanations of new tools.

## Collaboration and Communication Preferences
Guided planning process; explain new tools. Prioritize a working demo and keep the project small enough for the hackathon.

## Areas Where the Learner Wants Ownership
Not established.

## Likely Support Needs
Beginner-friendly explanations of tools and planning decisions. Help translate a broad product idea into a small, buildable proof of concept.

## Review Format

markdown

## Notes and Open Questions
No existing code should be used for this project, per the learner.
